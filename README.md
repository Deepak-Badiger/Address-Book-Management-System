# Address Book Management System

A console-based Address Book Management System developed in C. This project allows users to efficiently manage contact information using structures, arrays, pointers, string manipulation, and file handling.

## Features

- Add a new contact
- Search for contacts
- Edit existing contact details
- Delete contacts
- Display all contacts
- Validate name, phone number, and email
- Prevent duplicate phone numbers and email addresses
- Save contacts to a file
- Load existing contacts automatically
- Menu-driven console interface

## Contact Details

Each contact contains:

- Name
- Phone Number
- Email Address

## Technologies Used

- C Programming
- Structures
- Arrays
- Pointers
- String Handling
- File Handling
- Makefile
